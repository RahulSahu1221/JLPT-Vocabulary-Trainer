## Overview

**RONIN** is a modern **Progressive Web Application (PWA)** for learning **JLPT  Japanese vocabulary and kanji** through a structured and engaging study experience.

The application combines **Spaced Repetition (SRS)**, **interactive flashcards**, **quizzes**, **educational games**, **kanji learning**, **analytics**, **XP progression**, and **offline study** into a single browser-based platform.

Designed with a premium glassmorphism interface and built entirely with **Vanilla HTML, CSS, and JavaScript**, RONIN demonstrates that a feature-rich educational application can be created without frontend frameworks.

---

### Learning

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rahulsahu1221/RONIN-A-JLPT-Vocabulary-Trainer.git
cd RONIN-A-JLPT-Vocabulary-Trainer
```

Run locally:

```bash
npx serve .
```

or open `index.html` with **VS Code Live Server**.
